Грубо говоря, это макрокомпилятор, или хотя бы то, что пытается им казаться. 

  Идея проста – сделать такой компилятор, где любое живое существо сможет накодить собственный язык программирования благодаря системе макросов. А еще мне лень писать бекенд под каждую архитектуру. 

  У всех или многих макросов будут следующие общие черты:
Во-первых, Начинаются они с указания уровня nlevel, оно определяет порядок их матчинга с максимального указанного уровня до 0. Во-вторых,
макросы одного уровня выполняются в порядке их определения. Пока не определено как порядок импортов файлов с макросами будут влиять на их порядок матчинга. 
Далее указывается стадия, в данном случае единственно поддерживаемая это lex. Названия временные и в будущем будет возможность указать свои имя стадии, порядок и тип. 

  Планируются два основных типа стадий: flat и tree. 
Flat – преимущественно плоский поток токенов, его по своему усмотрению можно менять макросами, также на токены можно накладывать свойства. 
Tree - I don't know что там в будущем будет конкретно, но по сути это переписывание плоского потока токенов в ast.
	
  Касаемо текущего синтаксиса, вот он:
123level – задает уровень макроса
lex -  стадия макроса
<word> матчит любой токен, не являющийся переносом строки
<token> матчит любой токен.
<abcdr> матчит конкретный токен с указанным именем.
<abcdr 0> матчит с захватом токена работает и для случаев выше. 

<0> обращение к заматченому токену
<0>.abc  прочитает свойство токена если но есть.
<0>.abc  = abcde создает и/или устанавливает значение свойству.

0abc макропеременная всегда с числа начинается, если на не входит ни в какую команду то печатается в результат матчинга ее значение.

pint 0a
pstring 0b обьявления макропеременных типа строки и числа

0a = 123 присвоение значения 
pif a op b else l1 условие. Если истино то идет дальше, если ложное прыгает на метку указанную правее else. 
Поддерживает только макропеременные, числа и одиночные токены для сравнения. 

plabel l1 определение метки
pgoto l1 безусловный переход

pcansel отмена выполнения макроса, никакие изменения не сохраняются.

pnewline добавляет новую строку.
pend конец макроса.
Пример:

clone(abc,6,default)
clone(abc,5,newln)



0level lex <clone><(><word 0><,><word 1><,><word 2><)>
pint 0a = 0
pint 0b = <1>

pstring 0j = <2>


plabel rep
pif 0a < 0b else end

<0>

pif 0j == newln else skip

pnewline

plabel skip

0a += 1
pgoto rep
plabel end

pend
